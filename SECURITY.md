# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential. Use the
repository's private vulnerability reporting flow under **Security > Advisories > New
draft security advisory**.

Include the affected version, impact, reproduction steps, and a minimal proof of
concept. Do not include customer telemetry, access tokens, connection strings, model
keys, or other secrets.

## Supported versions

Security fixes are applied to the latest tagged release and the default branch.
